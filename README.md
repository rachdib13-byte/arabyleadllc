# ARABYLEAD LLC Website

Premium static website for ARABYLEAD LLC, built with HTML5, CSS3, and vanilla JavaScript.

## Project Structure

```text
/
| index.html
|
|-- css/
|   `-- style.css
|
|-- js/
|   `-- script.js
|
|-- images/
|
|-- assets/
|   |-- favicon.svg
|   |-- og-image.svg
|   `-- logo.svg
|
|-- robots.txt
|-- sitemap.xml
`-- README.md
```

## Run Locally

Open `index.html` directly in a browser. No build tools, package managers, or servers are required.

## Deploy to GitHub Pages

1. Upload the project files to a GitHub repository.
2. Open repository settings.
3. Enable GitHub Pages from the main branch root.
4. Visit the generated GitHub Pages URL.

## Notes

The site includes semantic HTML, responsive layout, smooth scrolling, animated counters, FAQ accordion, loading animation, back-to-top button, SEO metadata, Open Graph tags, Twitter cards, `robots.txt`, and `sitemap.xml`.
